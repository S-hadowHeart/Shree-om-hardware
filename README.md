# 🛒 Shree Om Hardware – E-Commerce Platform

Full Stack Development Project  
RK University – 2026  

An e-commerce platform for selling premium hardware parts such as door handles, locks, hinges, tower bolts, and accessories.

---

## 🚀 Project Overview

Shree Om Hardware is a B2C e-commerce web application built using:

- **Frontend:** React.js
- **Backend (Track 1):** Express.js (Node.js)
- **Backend (Track 2):** ASP.NET Core (.NET)
- **Database:** MongoDB / SQL
- **Authentication:** JWT
- **Architecture:** RESTful API + MVC

## ✨ Features

### 🛍️ Customer Features
- Product listing & filtering
- Product details with images & specs
- Add to cart & wishlist
- User registration & login
- Checkout & order tracking
- Search by name/SKU
- Responsive design (Mobile/Desktop)

### 🛠️ Admin Features
- Dashboard with sales metrics
- Product management (CRUD)
- Order management
- User management
- Low stock alerts
